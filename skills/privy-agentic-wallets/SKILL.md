# Privy Agentic Wallets

Create crypto wallets with [Privy](https://privy.io) that AI agents control autonomously with policy-based guardrails.

## Use Cases

- **Trading & DeFi** — Swaps, rebalancing, yield farming
- **Payments** — Pay for APIs, tip creators, subscriptions
- **On-chain Automation** — Governance votes, ENS renewal, bridging
- **Agent-to-Agent** — Pay other agents, escrow, pool resources
- **NFTs** — Mint, purchase, manage collections

## Quick Start

### 1. Get Credentials
- [dashboard.privy.io](https://dashboard.privy.io)
- Copy App ID and App Secret

### 2. Environment
```bash
export PRIVY_APP_ID="your-app-id"
export PRIVY_APP_SECRET="your-app-secret"
```

### 3. Install
```bash
git clone https://github.com/privy-io/privy-agentic-wallets-skill.git .cursor/skills/privy
```
