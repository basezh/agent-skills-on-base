# Alchemy for AI Agents

Give your agent blockchain data. Pay for compute with x402. Build apps onchain.

## Install

```bash
npx skills add alchemyplatform/skills -g --yes
```

Compatible with Claude Code, Codex, Cursor, OpenClaw, and more.

## Features

- **Agentic signup** — Sign up with onchain wallet, prepay for compute via x402
- **Node APIs** — Core RPC for 100+ chains
- **Data APIs** — Tokens, NFTs, prices, balances, portfolio
- **Solana APIs** — Yellowstone gRPC, DAS APIs
- **Webhooks** — Push onchain events to your backend

## Example Prompts

- "Build a crypto dashboard showing historical prices (ETH, BTC, SOL) using Alchemy"
- "Build a transaction simulation developer tool using Alchemy"
- "Build an NFT viewer showing top NFTs and last 5 transfers for BAYC, Crypto Coven, Doodles"
