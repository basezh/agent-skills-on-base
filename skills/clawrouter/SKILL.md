# Clawrouter

Agent-native LLM router for OpenClaw. Route every request to the right model at the right price.

## Features

- 15-dimension scoring
- <1ms local routing
- 41+ models
- One wallet, zero API keys
- Optimized for autonomous agents

## Install

```bash
git clone https://github.com/BlockRunAI/ClawRouter
```
