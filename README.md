[Base](https://base.org) is the onchain home for AI agents.

[@basezh](https://x.com/basezh) has curated a collection of [Agent Skills](https://agentskills.io) built on [Base](https://base.org), covering infra, wallets, markets, DeFi, social, and creation, etc.

Try installing these Skills and your agent can immediately gain onchain capabilities, interacting with protocols, completing tasks, and even starting to earn autonomously.

We believe more and more onchain apps will redesign their interfaces for agents. Enjoy the acceleration brought by AI.

## Install Skills

This repository is a curated hub for Base-related Agent Skills. All skills in this repository are forked and ready to load.

To install all skills from this repository, clone it and copy the skill folders into your OpenClaw `skills/` directory:

```bash
git clone https://github.com/basezh/agent-skills-on-base.git
cp -r agent-skills-on-base/skills/* ~/.openclaw/skills/
```

You can also install individual skills from the Original Link listed above.

**Install via agent conversation:**

```
Read <url>/SKILL.md or github.com/<org>/skills docs, and follow the instructions to install the skill.
```

**Repository structure**

```text
agent-skills-on-base/
├── README.md
└── skills/
    ├── base/
    │   ├── SKILL.md
    │   └── skills/
    ├── quicknode/
    │   └── SKILL.md
    ├── bankr/
    │   ├── SKILL.md
    │   ├── bankr/
    │   ├── siwa/
    │   ├── onchainkit/
    │   └── ...
    ├── clawnch/
    │   └── SKILL.md
    └── ...
```

Some skills require API keys or additional configuration. Please check each skill's `SKILL.md` before use.

```bash
git clone https://github.com/basezh/agent-skills-on-base.git

```
